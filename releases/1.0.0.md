## Arches Modular Reports 1.0.0 Release Notes

### Breaking changes

- Switches from `arches-component-lab` to `arches-vue-components`. [#PR](https://github.com/archesproject/arches-modular-reports/pull/PR)

    - `arches_component_lab` has been replaced by `arches_vue_components` in `INSTALLED_APPS` (`arches_modular_reports/settings.py`).
    - The URL include for the component library has changed from `arches_component_lab.urls` to `arches_vue_components.urls` (`arches_modular_reports/urls.py` and `arches_modular_reports/arches_modular_reports_urls.py`).
    - Any project code importing from `@/arches_component_lab/...` must be updated to import from `@/arches_vue_components/...` instead.
    - `createVueApplication` is now imported from `@/arches_vue_components/application/create-vue-application.ts` instead of `utils/create-vue-application`, and its signature has changed from positional arguments to a single options object: `createVueApplication({ component, themeConfiguration, initialProps })`.

### Upgrading Arches Modular Reports

1. Upgrade python package
    ```
    pip install --upgrade arches-modular-reports==1.0.0
    ```

1. Switch your project from `arches-component-lab` to `arches-vue-components`:

    - Update your project's Python dependencies to remove `arches-component-lab` and add `arches-vue-components`, then reinstall.

    - Update your project's `package.json` to remove the `arches-component-lab` dependency and add:
        ```json
        "arches-vue-components": "archesproject/arches-vue-components#stable/1.1.0"
        ```
        then reinstall your frontend dependencies:
        ```
        rm -r node_modules; rm package-lock.json
        npm install
        ```

    - In your project's `settings.py`, replace `arches_component_lab` with `arches_vue_components` in `INSTALLED_APPS`.

    - In your project's `urls.py`, replace the `arches_component_lab.urls` include with `arches_vue_components.urls`.

    - Update any project code importing from `@/arches_component_lab/...` to import from `@/arches_vue_components/...` instead.

    - If your project calls `createVueApplication` directly, import it from `@/arches_vue_components/application/create-vue-application.ts` and update the call to pass a single options object: `createVueApplication({ component, themeConfiguration, initialProps })`.

1. Run migrations
    ```
    python manage.py migrate
    ```

1. Update webpack build
    ```
    npm run build_development
    python manage.py collectstatic
    ```

1. If you are running Arches on Apache, restart your server:
    ```
    sudo service apache2 reload
    ```
