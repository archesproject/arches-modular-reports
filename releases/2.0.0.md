## Arches Modular Reports 2.0.0 Release Notes

### Bug fixes

- Updates webpack build to match latest Arches core. [#190](https://github.com/archesproject/arches-modular-reports/pull/190)

- Requires Python 3.12+. [#190](https://github.com/archesproject/arches-modular-reports/pull/190)
- Requires Arches >= 8.0.0. [#PR](https://github.com/archesproject/arches-modular-reports/pull/PR)
- `pgtrigger` is required in `INSTALLED_APPS`. [#PR](https://github.com/archesproject/arches-modular-reports/pull/PR)

### Upgrading Arches Modular Reports

1. Upgrade python package
    ```
    pip install --upgrade arches-modular-reports==2.0.0
    ```

1. Ensure `pgtrigger` is listed in your project's `INSTALLED_APPS` alongside `arches_modular_reports`, `arches_querysets`, and `arches_vue_components`.

1. Update your project's `package.json`:
    ```json
    "arches-vue-components": "archesproject/arches-vue-components#dev/2.0.x"
    ```
    then reinstall your frontend dependencies:
    ```
    rm -r node_modules; rm package-lock.json
    npm install
    ```

1. Run migrations
    ```
    python manage.py migrate
    ```

1. Update webpack build
    ```
    npm run build_development
    python manage.py collectstatic
    ```

1. If you are running Arches on Apache, restart your server:
    ```
    sudo service apache2 reload
    ```
